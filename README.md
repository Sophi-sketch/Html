# Landing Page — Escritório de Advocacia

Projeto educacional de página única feito com HTML5, CSS3 e JavaScript, usando Flexbox como principal técnica de layout.

## Orientador

Hudson Neves

## Estrutura

- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: estilos, Flexbox e responsividade.
- `js/menu.js`: comportamento do menu de navegação em dispositivos móveis.
- `assets/`: logotipo, ilustrações, ícones e avatares em SVG.

Os arquivos de código contêm comentários didáticos que explicam cada bloco funcional. A pasta `assets` reúne desenhos vetoriais que o navegador renderiza sem perda de qualidade.

## Como executar

Abra o arquivo `index.html` diretamente no navegador ou use a extensão Live Server no VS Code.
